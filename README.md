## Overview

REPENTOGON (Repentance+ Gone) is an open-source modding framework for The Binding of Isaac: Repentance that exposes hundreds of additional Lua API functions and callbacks not present in the vanilla modding interface. It is the required dependency for a large portion of the advanced Isaac modding community, enabling features like custom HUD elements, entity behavior overrides, save file access, and in-game console enhancements.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **REPENTOGON** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Extended Lua API** | Hundreds of additional callbacks and functions beyond vanilla Isaac API |
| **Custom HUD** | Full HUD rendering API for mods to draw custom overlays and elements |
| **Entity Overrides** | Override NPC and pickup behavior at a low level for advanced mods |
| **In-Game Console** | Enhanced developer console with autocomplete and better error output |
